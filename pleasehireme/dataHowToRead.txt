style string options for metadata:
--
grouping keywords:
OBJ - next order nested folder is an object
LIST - next order nested folder is an unordered list
--
"-" - this seperates one heirarchical level from another
"," - this indicates another object in the same heirarchical level
"[]" - this gives an explicit name for the groupings at a level, used after a grouping keyword
"<>" - this indicates a group of things in an object at the same level
"()" - this indicates that the specified group can be found under this name in the object


string style guide:

 - "^" - the next character should be uppercase (unless overridden with "\^")
 - "_" - the next character should be lowercase (unless overridden with "\_")
 - "{}" - everything within the brackets is invisible to the text but appears with a blue highlight underneath. When the user clicks it, the text expands based on definitions
 L__ of the same scope. If the definition cannot be found, the program will check the local dictionary for the terms, then check the inner recursive folders, then continue
 L__ checking outer folders until everything is searched, at which point it will throw an error.
 - "/" - used for dates (and informally in literal text)

Reserved terms:
METADATA
HASMETA - this object owns its own METADATA key
STYLE
COLOR1, COLOR2: primary and secondary colors for specifying a block. Both are a type of COLOR
COLOR - indicates a color, in hex as #FFFFFF
DATE - an object type that represents a date, typically accessed as "(M)M/(D)D/YY": 19/39/26
START - a specific type of DATE that represents the beginning of an event
END - a specific type of DATE that represents the ending of an event
PRESENT - a specific type of END that represents the current date
FUTURE - a specific type of PRESENT that indicates the event has not happened yet and has an unconfirmed future date
LOCATION - represents a location, which is either in a typical postal form followed by a zip code, or raw long/lat coordinates if first character is #
DESCRIPTION - an object that represents a standardized way to show text. Contains MAIN. May contain other strings, presumably linked to by MAIN's accordian text.
MAIN - a string containing the main text of a description. May contain hidden text in {} brackets
NAME - the name of a person
PHONE - a phone number in 999-999-9999 or 9999999999 format
